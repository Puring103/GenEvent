# GenEvent v0.10.0 Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stamp and release GenEvent v0.10.0 — the stability transition release that formalises the runtime contract (Init idempotency, IsInitialized, explicit errors, HasPublisher, GetSubscriberCount).

**Architecture:** All runtime changes are already merged to main. This plan handles version stamping, generated-code version string update, Unity artefact sync, and final verification only. No new feature code is written here.

**Tech Stack:** C# / .NET, MSBuild csproj versioning, BenchmarkDotNet, NUnit, Unity asset copy via MSBuild targets.

- `BootstrapContractTests.cs` with 8 tests covering all of the above.
- README runtime contract section in both English and Chinese.
- 148/148 tests pass on current `main`.

What remains: **version stamping** and **artefact sync**.
